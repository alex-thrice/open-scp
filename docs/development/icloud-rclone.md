# Google Drive и iCloud/rclone: расширенная конфигурация

Эти сведения предназначены разработчикам и сопровождающим приложения.
Пользовательская инструкция описывает настройку через интерфейс:
[English](../user/icloud.md) / [Русский](../user/icloud.ru.md).

## Путь к программе и конфигурации

Приоритет поиска исполняемого файла: сохранённая настройка OpenSCP →
`OPENSCP_RCLONE_PATH` → `rclone` из `PATH`. В пользовательских инструкциях
рекомендуется только **Настройки → Дополнительно → Google Диск / iCloud Drive / rclone**.

Для локальной разработки можно задать путь в окружении процесса:

```powershell
$env:OPENSCP_RCLONE_PATH = 'C:\Tools\rclone\rclone.exe'
```

OpenSCP использует обычный конфиг rclone. Нестандартное расположение задаётся
абсолютным путём в `RCLONE_CONFIG` перед запуском приложения. Для зашифрованного
конфига поддерживается `RCLONE_CONFIG_PASS`; интерактивный запрос пароля
конфига в дочернем процессе отключён.

Пути к программе и конфигу не принимаются через профиль или импорт. Сохранённый
путь к программе локален для компьютера и не экспортируется с профилями.

## Google Drive

Remotes типа `drive` настраиваются вне OpenSCP с собственным OAuth-клиентом
по [инструкции Google/rclone](google-oauth.md). Приложение выбирает готовый remote
и не получает Google OAuth-токены в свою базу. Типы `drive` и `iclouddrive`
обнаруживаются отдельно; имя remote не считается подтверждённым email аккаунта.
Удаление профиля OpenSCP не удаляет Google remote и его credentials.

## Вход iCloud и восстановление

Настройка выполняется через внешний rclone. Пароль передаётся в `rclone obscure -`
через stdin; ответы и состояние следующих шагов — в окружении дочернего процесса,
без секретов в аргументах команд. Cookies, непрозрачное состояние входа и исходные
сообщения rclone не передаются в renderer.

При отмене приложение пытается удалить созданный незавершённый remote. Существующие
remotes не перезаписываются. После успешного входа remote остаётся в rclone, даже
если пользователь позже отменит редактирование профиля OpenSCP. При аварийном
завершении незавершённый remote может остаться; его можно проверить и удалить
через `rclone config`.

Ранее настроенные `iclouddrive` remotes доступны через выбор готового подключения
в OpenSCP. Настройка через `rclone config` также поддерживается. После внешних
изменений выполните **Проверить rclone** в дополнительных настройках приложения.

При истечении trust token может потребоваться повторный вход. Для восстановления
существующего remote можно использовать `rclone config reconnect NAME:`, где
`NAME` — фактическое имя подключения, затем переподключить панель OpenSCP.
Срок сессии и условия ADP описаны в [документации rclone](https://rclone.org/iclouddrive/).

Реальные аккаунты и платформы требуют отдельной [приёмки](../testing/icloud.md).
