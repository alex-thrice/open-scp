OpenSCP 0.3.1 improves session safety, customization, and application updates.

## Tabs, queue, and shortcuts

- Ask for confirmation before closing a tab, with an option to disable the prompt in
  settings.
- Warn before quitting while transfers are active so queued work is not interrupted
  accidentally.
- Start each application session with a clean transfer queue instead of restoring its history.
- Allow application keyboard shortcuts to be reassigned from settings.

## Application updates

- Check GitHub Releases for updates automatically, while leaving automatic download and
  installation disabled by default.
- Show an update indicator in the main toolbar and open the Updates settings page from it.
- Allow update checks, downloads, and installation behavior to be controlled separately.
- Publish updater metadata with release packages and report missing release metadata separately
  from connection failures.

## Platform and interface fixes

- Preserve the correct `.app` path when selecting an external editor on macOS.
- Use the application-styled file picker control when importing `known_hosts`.
- Avoid starting the regular CI workflow a second time for version tags.

Release packages are built, installed, and smoke-tested automatically on Windows, Linux, and
macOS before the GitHub Release is published.
