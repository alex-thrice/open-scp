OpenSCP 0.3.4 adds file drag-out, clearer search navigation, and improved update handling on macOS.

## File drag-out

- Drag selected local files into other desktop applications that accept files.
- Prepare files from SFTP, FTP, or S3 through the toolbar or context menu, then drag the
  downloaded temporary copies using the new drag handle.
- Show download progress and support cancellation while preparing remote files.
- Support up to 100 regular files per drag. Folders and symbolic links continue to use
  transfers between OpenSCP panes.

## Search navigation

- Add previous and next match buttons beside the file search field.

## Application updates

- Open the release page for manual installation when updating an unsigned macOS build.

Release packages are built, installed, and smoke-tested automatically on Windows, Linux, and
macOS before the GitHub Release is published.
