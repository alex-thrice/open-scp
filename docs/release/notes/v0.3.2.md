OpenSCP 0.3.2 improves desktop navigation, file operations, and packaged application updates.

## Desktop integration

- Add native File, View, Window, and Help menus with platform-appropriate commands.
- Add an About OpenSCP dialog with the installed version and a link to the GitHub project.
- Remove the unused Edit menu.

## File management

- Create empty text files from the file-pane toolbar or context menu.
- Keep the current file sorting when a pane is refreshed.
- Skip file-grid column headers during keyboard tab navigation.

## Application updates

- Fix update checks in installed builds by resolving the packaged updater runtime correctly.

Release packages are built, installed, and smoke-tested automatically on Windows, Linux, and
macOS before the GitHub Release is published.
