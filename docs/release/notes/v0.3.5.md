OpenSCP 0.3.5 improves SFTP transfer speed on remote servers and adds transfer settings.

## Faster SFTP transfers

- Send multiple upload and download requests at once instead of waiting for each block.
- Use WinSCP queue defaults: up to 64 outstanding blocks for uploads and 32 for downloads.
- Keep memory use bounded and report upload progress after the server acknowledges data.
- Preserve cancellation and resume behavior, and handle download responses arriving out of order.

## Transfer settings

- Configure SFTP upload and download concurrency under Settings → Transfers.
- Choose values from 1 to 128, with a button to restore WinSCP defaults.
- Save settings across restarts and apply changes when the next file starts transferring.
- Use a value of 1 for servers that require sequential requests.

Large-file uploads and downloads were compared with WinSCP over SFTP, FTP, and S3 using
local test servers, with SHA-256 checks confirming file integrity. Actual speeds depend
on the server and network.

Release packages are built, installed, and smoke-tested automatically on Windows, Linux, and
macOS before the GitHub Release is published.
