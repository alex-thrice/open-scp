OpenSCP 0.4.6 preserves local folders when closing remote tabs and improves context menus.

## Local folders

- Restore each pane's last local directory after closing the final remote tab,
  including when both panes were connected to Google Drive.
- Prevent old tab history from replacing the restored folders with unrelated paths.
- Keep local folders during the current run even when persistent path history is
  disabled or a connection starts before the latest path finishes saving.

## Context menus

- Show readable Google Drive folder paths in the Copy command.
- Truncate long labels without hiding keyboard shortcuts, and show the full label
  in a tooltip.

Release packages are built, installed, and smoke-tested automatically on Windows, Linux, and
macOS before the GitHub Release is published.
