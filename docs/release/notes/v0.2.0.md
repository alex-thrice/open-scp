OpenSCP 0.2.0 focuses on faster file navigation, safer transfers, and a smoother SFTP workflow.

## Highlights

- Open an SSH terminal directly from an active SFTP panel. PuTTY is used on Windows, while
  macOS and Linux use the system terminal and OpenSSH.
- Search the active file pane by typing, edit the query in a compact search panel, and move
  between matches with the arrow keys.
- Start copies immediately and choose overwrite, skip, or keep-both only when a destination
  conflict is actually detected.
- Open local files in their default application and edit files with F4 using a configurable
  external editor.

## Connection and session improvements

- Restore workspace tabs, local paths, and per-profile remote paths between sessions. Path
  history can be disabled in Settings.
- Restore the main window position, size, maximized state, and full-screen state.
- Show detailed SFTP connection progress and allow an in-progress connection to be cancelled.
- Prompt for a missing or rejected SFTP password without requiring the whole profile to be
  edited, and save a corrected password only when explicitly requested.

## Keyboard and usability

- F5 copies the current selection, Ctrl+F5 refreshes the active file pane, and F4 opens the
  selected file in the configured editor.
- Preserve keyboard focus after directory navigation so arrow-key browsing can continue.
- Improved toolbar button states and editor executable selection on Windows.

Release packages are built and smoke-tested automatically on Windows, Linux, and macOS before
the GitHub Release is published.
