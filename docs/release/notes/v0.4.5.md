OpenSCP 0.4.5 fixes repeated copies to Google Drive.

## Google Drive

- Fix false conflicts when copying a file again after renaming, moving or trashing
  the previous copy, even when the destination folder is empty.
- Fix the same false conflict when recreating a previously created folder.
- Keep safe retry and resume behavior for interrupted or uncertain uploads.

Release packages are built, installed, and smoke-tested automatically on Windows, Linux, and
macOS before the GitHub Release is published.
