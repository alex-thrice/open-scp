OpenSCP 0.3.0 adds FTP connections to the dual-pane file workflow while preserving the
existing SFTP and S3 experience.

## FTP connections

- Create and edit FTP profiles with host, port, username, initial directory, and timeout
  settings.
- Store passwords with the operating system's secure storage and prompt for missing or
  rejected credentials through the shared connection flow.
- Keep a permanent warning visible for unencrypted FTP connections and distinguish them from
  secure connections in the interface.
- Use passive mode, UTF-8 paths, and MLSD directory listings with a LIST fallback for broader
  server compatibility.

## File operations and transfers

- Navigate directories, inspect files, upload and download, create folders, rename or move
  entries, and delete directory trees over FTP.
- Run local-to-FTP and FTP-to-local transfers through the common queue with progress,
  cancellation, retry, and overwrite, skip, or keep-both conflict handling.
- Map FTP failures to safe, localized errors without exposing stored credentials.

## Compatibility and validation

- Add a reproducible vsftpd fixture and FTP provider contract coverage.
- Cover Unicode paths, spaces, password correction, restart recovery, and encrypted credential
  persistence with automated tests.
- Keep FTPS out of scope for this release; FTP profiles clearly represent an unencrypted
  protocol.

Release packages are built and smoke-tested automatically on Windows, Linux, and macOS before
the GitHub Release is published.
