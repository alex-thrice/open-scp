OpenSCP 0.4.4 improves text editing and password entry in connection forms.

## Text editing

- Restore the native Edit menu and standard macOS shortcuts for copying, pasting,
  cutting, selecting all, undoing and redoing text edits.
- Add native text-field context menus with Cut, Copy and Paste commands.
- Enable commands according to the field's selection and editing capabilities.

## Password entry

- Add show/hide buttons to password, key passphrase, S3 secret and session token fields,
  including the password prompt shown when connecting again.
- Preserve the entered value, focus and cursor selection when changing visibility.
- Hide values again when submitting, resetting or clearing a field.

Release packages are built, installed, and smoke-tested automatically on Windows, Linux, and
macOS before the GitHub Release is published.
