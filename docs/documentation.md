# Документация: GitHub, сайт и демонстрации

## Где что размещать

| Материал                              | Основное место                             | На другой площадке                       |
| ------------------------------------- | ------------------------------------------ | ---------------------------------------- |
| Описание, возможности, выбор загрузки | Сайт                                       | Краткий обзор и скачивание в README      |
| Первое подключение и копирование      | Сайт, русский и английский                 | Версионируемые инструкции в `docs/user/` |
| Скриншоты                             | Основной снимок в README, галерея на сайте | Исходные PNG в `docs/images/`            |
| Короткие демонстрации                 | Сайт, видео с постерами                    | Сценарий и команда записи в репозитории  |
| Установщики и история версий          | GitHub Releases                            | Кнопки сайта ведут на Releases           |
| Ошибки и предложения                  | GitHub Issues                              | Ссылка со страницы помощи                |
| Сборка, тесты, архитектура, ADR       | GitHub, `docs/`                            | Ссылка «Исходный код» на сайте           |
| Конфиденциальность и условия          | Сайт, `/privacy/` и `/terms/`              | При необходимости ссылки из README       |

README отвечает на вопросы «что это», «подойдёт ли мне», «где скачать» и «как начать».
Пользовательские инструкции описывают действия и результат. Регистрация OAuth,
настройка CI и устройство кода относятся к технической документации. Ограничения
готовой программы, например отсутствие FTPS или зависимость iCloud от rclone,
должны быть видны пользователю.

Сайт хранится в локальном исключённом из Git каталоге `site/vps/openscp-site/`.
Он не включается в коммиты приложения. Публичный комплект нужно собирать отдельно
от локальных стендов OAuth и записей верификации Google.

## Языки сайта

- Русская версия сохраняет `/`, `/privacy/`, `/terms/`.
- Английская использует `/en/`, `/en/privacy/`, `/en/terms/`; руководство —
  `/guide/` и `/en/guide/`.
- На русских адресах небольшой внешний скрипт при первом посещении выбирает язык
  по `navigator.languages`: первый поддерживаемый русский или английский;
  английский — запасной. Английские адреса всегда открывают английский текст.
- Переключатель Русский / English сохраняет выбор в `localStorage` с приоритетом
  над языком браузера. Без хранилища работают обычные ссылки.
- Без JavaScript все страницы и переключатель доступны. Исходный HTML содержит
  полный текст. Выбор языка и его локальное хранение описываются в политике.
- Геолокация и определение IP для выбора языка не нужны.

## Снимки и ролики

Снимки создаёт настоящее приложение Electron с вымышленными файлами,
зарезервированными адресами `*.example.com`, отдельным профилем и ограниченным
локальным корнем. Профили галереи не подключаются к настоящим серверам.
Копирование действительно переносит файлы и проверяет содержимое. Эти материалы
не имитируют подтверждённую работу с настоящим облачным аккаунтом.

```bash
pnpm docs:media
pnpm docs:media -- --video
pnpm docs:media -- --video --language=en
```

PNG на двух языках сохраняются в `docs/images/`, записи — в игнорируемом
`test-results/documentation-media/`:

| Ролик                      | Содержание                                              | Размещение         |
| -------------------------- | ------------------------------------------------------- | ------------------ |
| `copy-{en,ru}.webm`        | Выделение, F5, проверка назначения, результат и очередь | Начало руководства |
| `connections-{en,ru}.webm` | Папки профилей и поиск вымышленных серверов             | Подключения        |
| `appearance-{en,ru}.webm`  | Настройки и смена темы                                  | Интерфейс          |

Для видео нужен FFmpeg от Playwright: `pnpm exec playwright install ffmpeg`.
Linux требует графическую сессию или Xvfb и ключницу, как обычные UI-тесты.

Видео размещается с кнопкой воспроизведения, постером, пояснением и `preload="none"`.
Автовоспроизведение отключено. Видеофайлы не хранятся в истории исходников приложения.
Снимки обновляются после заметных изменений интерфейса. Для каждой локали используются
отдельные записи и обложки с соответствующим языком интерфейса. Обзорные ролики и видео проверки OAuth —
разные материалы; реальные аккаунты из записей для Google на сайте не используются.
