# ADR 0007: Облако Mail.ru через WebDAV

- Статус: принято для T31.
- Дата: 2026-10-19.

## Контекст

T31 добавляет Облако Mail.ru к общим панелям и очереди. Официальная справка Mail описывает
WebDAV по HTTPS с паролем внешнего приложения:
https://help.mail.ru/cloud/desktop/webdav/.
Нужен самостоятельный клиент без монтирования диска средствами ОС и без доступа renderer
к протокольному клиенту или сохранённому паролю.

## Решение

- Добавить вид профиля и пути `mailru`. Профиль содержит имя, email аккаунта, начальный
  каталог, timeout и ссылку на пароль приложения. Endpoint фиксирован:
  `https://webdav.cloud.mail.ru`; URL и настройки TLS из renderer не принимаются.
- Путь — абсолютная строка относительно корня аккаунта. Сегменты кодируются по отдельности;
  traversal, управляющие символы и неоднозначные href отклоняются. Имена с `%`, `#`, `?`,
  Unicode и XML-символами сохраняются без повторного декодирования.
- HTTP/WebDAV, XML parser и Basic credentials существуют только в main process.
  Redirect не выполняется автоматически и никогда не переносит Authorization на другой
  адрес. XML имеет ограничение размера; DTD и объявления сущностей запрещены.
- Использовать `PROPFIND` Depth 0/1, `GET`, `PUT`, `MKCOL`, `MOVE`, `DELETE`.
  Учитывать статусы отдельных `response`/`propstat`, включая частичный результат удаления.
  ETag используется как идентификатор версии, не как checksum.
- Объявить настоящие каталоги, read/write, mkdir, delete и rename. Не объявлять атомарность
  rename, POSIX permissions, симлинки, server-side copy, checksum и resume. Поведение сервиса
  проверяется отдельным реальным smoke; fixture не доказывает совместимость Mail.ru.
- Очередь загружает файл во временное имя и проверяет размер до публикации. MOVE использует
  `Overwrite: F` или явное `Overwrite: T`; предварительного DELETE назначения нет.
  Ошибка публикации с неопределённым результатом остаётся requiring-review общей очереди.
  Прерванный PUT может оставить временный файл; автоматическое продолжение не предлагается.
- Для PUT без overwrite применять `If-None-Match: *`; при ожидаемой версии — `If-Match`.
  Read с ожидаемым ETag также условный. Скрытые автоматические повторы записи запрещены.
- Добавить типизированные ошибки квоты и ограничения запросов с RU/EN-сообщениями.
  Отказ HTTP 403 во время начальной проверки корня передавать как отдельную безопасную
  ошибку `MAILRU_WEBDAV_ACCESS_DENIED`: предложить проверить email, пароль приложения
  и право «Полный доступ к Облаку», разрешить повторный ввод. Это не подтверждает неверный
  пароль: отказ возможен и по политике аккаунта. После подключения 403 отдельных операций
  сохраняет обычную семантику недостаточных прав и не вызывает повторную авторизацию.
  Пароль VK ID и обычный пароль не используются для WebDAV; вход через браузер не добавляется.
  Сохранённые профили предыдущих видов не меняются; JSON metadata в SQLite позволяет
  добавить вариант без изменения таблиц. Архив профилей остаётся v1 с новым kind.
- Общую работу со ссылкой на секрет вынести в отдельные функции. Фабрика сессий и helpers
  путей поддерживают новый вариант без превращения Mail.ru в SFTP/FTP по умолчанию.
- Для интеграционных тестов разрешить явное внедрение транспорта в main process.
  В development Electron fixture URL допускается только при отдельном тестовом флаге,
  на loopback и при `!app.isPackaged`; профиль и production endpoint от него не зависят.

## Последствия

Mail.ru использует существующий парольный диалог, независимые вкладки, последние пути,
secret-free импорт/экспорт, локализованные ошибки и Transfer Engine. Upload завершается только
после ответа PUT и успешной публикации MOVE. Секрет не возвращается в snapshot или diagnostics.
Не заявляются блокировки WebDAV LOCK, продолжение передачи и гарантированная атомарность
операций сервиса. Доступность аккаунта, тарифные ограничения и реальные особенности MOVE
подтверждаются на тестовом аккаунте отдельно от воспроизводимых HTTP-тестов.

## Отклонённые альтернативы

- Неофициальный API сайта Mail: документированный WebDAV покрывает объём первой итерации.
- Монтирование через ОС: добавляет внешнюю настройку и платформенные зависимости.
- Универсальный WebDAV-профиль: расширяет объём T31 и разрешённые сетевые адреса.
- Удаление назначения перед MOVE: создаёт риск потери прежнего файла при неудачной записи.
- Сохранение пароля аккаунта вместо пароля приложения: противоречит способу входа Mail.
